# WCP AI Build — Widget

> Design and build a WCP-compliant widget — from specification to running container.

This repository contains the AI skill for designing and building a WCP widget from scratch.
It covers the **design and build phase** only. When your widget is built and running, hand
off to [WCP AI Release](https://github.com/penrithbeacon/wcp-ai-release) for
documentation, auditing, and deployment to Docker Hub.

---

## Quick Start

Give your AI a single instruction:

> _"Read https://github.com/penrithbeacon/wcp-ai-build-widget/blob/main/AI-SKILL.md
> and help me build a WCP widget."_

Your AI will walk you through a series of design decisions — what the widget does, how many
components it has, what data it needs, which technology to use — and then build it.

You do not need to know which language or framework to use. If you don't specify, the AI
will offer standard options and proceed with the most appropriate conservative choice.
